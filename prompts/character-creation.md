# Prompt: Character Creation and Visual Translation
**For a supplied lore bible, character sheet, or physical description**

Use this when creating a new character or translating an existing character into the Estate Codex. This is a prompt template, not a generator.

---

## COPY FROM HERE

You are creating a character for a project that follows The Estate Codex. Read the supplied lore bible and physical descriptions before proposing anything.

### Source authority

The character's supplied canon determines identity. The Estate Codex determines presentation.

Do not make the character more aristocratic, Gothic, mystical, romantic, historically styled, or visually ornate merely because those things appear in the house style. The character must remain the person described by the source.

Preserve all supplied facts, including:
- Name, age, pronouns, and role.
- Face, skin, hair, build, stature, and identifying features.
- Clothing, accessories, and practical equipment.
- Personality, history, motivations, relationships, and affiliations.
- Cultural, geographic, and historical details.

Do not infer missing details from a name, image, aesthetic, or stereotype. If a detail is absent, mark it unspecified. Do not invent real-world facts, quotations, book titles, institutions, or shared history.

### First produce a canon extraction

Create four lists:

1. **Established facts** — explicitly stated in the source.
2. **Visual anchors** — features that must remain consistent between portrait, sprite, and scene art.
3. **Open details** — details the source does not establish.
4. **Optional proposals** — new ideas that could fit, clearly marked non-canonical.

Do not proceed as if optional proposals are facts.

### Then create the character presentation

Select a leading Codex register:
- Estate of the Crown for formal portrait framing, identity, heraldry, and UI presentation.
- The Last Abbey for historical memory, devotional melancholy, and environmental context.
- The Broken Measure / Rootbound for philosophical or symbolic treatment.

Explain the choice in terms of the character, not generic aesthetic vocabulary.

Translate the character into:
- Silhouette and pose.
- Face and expression.
- Clothing and material.
- Palette, with role-specific colors.
- Lighting and background.
- Frame, border, heraldic or archival treatment, if appropriate.
- Details to preserve across future assets.

### If a pixel-art portrait is requested

Use the Genesis Codex constraints only if the brief requests this register:
- 128×128 pixel-art bust portrait unless another size is specified.
- Four 16-entry RGB333 palette banks overall; each tile selects one bank.
- No more than 16 colors from the selected palette line per tile.
- Crisp pixel clusters, deliberate dithering, hard-edged shading.
- No anti-aliasing, blur, smooth gradients, painterly texture, or post-process pixel filters.
- Gilt frame, oxblood and antique gold accents only where appropriate to the character.
- Readable silhouette at 32×32 preview size.

### Deliverables

Return:
1. Canon extraction.
2. Character visual identity sheet.
3. Portrait art direction.
4. Copy-ready image prompt.
5. Negative prompt.
6. Sprite translation notes, if requested.
7. Continuity checklist for future assets.

For the image prompt, repeat the most important source-specific physical details explicitly. Do not rely on phrases such as "same character as the reference" when a precise description can be included.
